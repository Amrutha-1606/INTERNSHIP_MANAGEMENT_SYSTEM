# Internship Management System

A simple web-based Internship Management System developed using **HTML, CSS, and JavaScript**.

## Features

- Add internship details
- View internship records
- Search students
- Delete internship records
- Stores data using Local Storage
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run it using **Live Server** or open it directly in a browser.
